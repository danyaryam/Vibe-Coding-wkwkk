buatkan issue.md yang berisi perencanaan untuk nanti diimplementasikan oleh junior programmer atau ai model yang lebih murah.

isi dari perencanaanya sebagai berikut :

buat tabel users:
id integer auto increment
name varchar 255 not null
email varchaar 255 not null
password varchar 255 not null (password merupakan hasil dari bcrypt)
created_at timestamp default current_timestamp

buatkan API untuk registrasi user baru
endpoint : POST /api/users

request body :

{
    "name" : "dany",
    "email" : "dany@localhost",
    "password" : "rahasia"
}

response body (succes) :

{
    "data" : "data"
}

response body (error) :

{
    "error" : "email sudah terdaftar"
}

struktur folder didalam src
- routes : ini berisi routing elysia js
- services : ini berisi logic bisnis aplikasi

struktur file
- routes : menggunakan format misal users-route.ts
- services : menggunakan format misal users-service.ts

jelaskan tahapan-tahapan yang harus dilakukan untuk mengimplementasi fitur ini, anggap nanti yang mengimplementasikan adalah junior programmer atau model ai yang lebih murah.
